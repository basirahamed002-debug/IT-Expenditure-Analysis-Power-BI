# IT Expenditure Analysis Dashboard 📊


## 📝 Project Overview
This project analyzes IT expenditure across different business areas, regions, and cost categories. The goal was to provide transparency into **Actual vs. Forecast vs. Planned** costs to identify overspending and budget variances.

## 📷 Dashboard Preview
!(Dashboard_Overview.png)


## 🔍 Key Insights
- **Budget Variance:** Identified a 15% overspend in the Europe region driven by external contractor costs.
- **Forecasting:** Q4 forecasts align closely with the Plan, indicating improved cost control measures.
- **Cost Drivers:** "Internal Labor" accounts for 60% of total IT spend.

## 🛠️ Tools Used
- **Power BI:** For data visualization and DAX measures.
- **Power Query:** For data cleaning and appending historical + future datasets.
- **Excel/CSV:** Raw data source.
